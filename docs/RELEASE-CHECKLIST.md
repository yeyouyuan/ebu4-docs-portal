# EBU4 上线检查清单

## 发布前

1. 依赖已安装：`npm install --prefix ebu4-site`
2. 测试通过：`npm --prefix ebu4-site test`
3. 本地可启动：`REDIS_URL=disabled npm start`
4. 管理员账号可登录

## 功能主链路

1. 前台首页可打开
2. `/docs` 可打开并能搜索
3. 扩展页可访问
4. 后台 AI 页面可保存配置并执行测试
5. 后台 SEO 页面可保存配置、生成 sitemap、读取推送日志
6. 后台升级页面可加载配置、执行检查、查看历史
7. 后台备份页面可创建备份、读取列表、执行恢复

## 降级场景

1. AI 未配置时，前台与后台都返回明确错误，不出现白屏
2. SEO 未配置外部平台参数时，页面可打开，推送接口返回可理解错误
3. 升级未配置时，页面可打开，检查/应用接口返回可理解错误
4. Redis 未配置时，开发环境可正常启动

## 生产确认

1. 已设置 `ADMIN_PASSWORD`
2. 已确认 `SITE_SQLITE_PATH` 或默认 `data/site.db` 的落盘位置
3. 已确认 `data/` 目录可写
4. 已确认日志目录可写
5. 已确认升级制品目录 `public/upgrade/` 的发布策略

## 回滚准备

1. 保留当前站点运行目录备份
2. 保留最新 SQLite 备份
3. 明确升级失败后的重启方式
4. 明确恢复数据库后的验证步骤
